# 学科易混对清单（出题对齐 + 批改抓手）

> 用途：出这些考点的题、或用户在这类题上答错时，直接查这张表对齐口径，别再临场推。
> 规则：本文件的每条都必须能在背诵稿/网课讲稿里找到原文；背诵稿没有的说法一律不写进来。

## 一、课程理论流派：阵营图（用户最大失分区）

| 阵营 | 成员 | 招牌关键词 |
|---|---|---|
| 学生中心 | **经验主义·杜威** | 儿童·经验·活动；主动作业占首要地位；课程组织心理学化；做中学 |
| 学生中心 | **存在主义·奈勒**（个人本位论） | 为自己存在负责；教材是自我发展和自我实现的手段；重人生价值与情感；和谐师生关系 |
| 学科中心 | **结构主义·布鲁纳** | 学科基本结构；螺旋上升；发现学习 |
| 学科中心 | **要素主义·巴格莱** | 人类文化的"**共同要素**"；**新三艺**（数学、自然科学、外语）；**国家和民族利益**；接受学习 |
| 学科中心 | **永恒主义·赫钦斯** | 教育**性质永恒不变**；引出**天性中共同的要素**；**古典学科/名著**；个人本位论 |
| 社会中心 | 社会改造主义·布拉梅尔德/弗莱雷 | 社会问题；改造社会 |
| 后现代 | **多尔** | **4R＝丰富性·循环性·关联性·严密性**（问"最重要"→**严密性**） |

**核心判据："对立"只在「学生中心 vs 学科中心」之间发生。** 学科中心内部三个流派互为同门，互不"对立"——"与结构主义相对立"的答案是**活动课程理论**，不是要素主义/永恒主义。

**永恒主义 vs 要素主义（两个都被叫"共同要素"，最容易倒）**
- 永恒主义＝**天性**的共同要素 ＋ **古典名著** ＋ 永恒不变
- 要素主义＝**文化**的共同要素 ＋ **新三艺** ＋ 国家民族利益

## 二、课程文本三层次与两个"依据"

**课程计划 → 课程标准 → 教材（教科书）**（＝课程设计的三个层次）；上一层是下一层的**依据**，下一层是上一层的**具体化**。

| 问法 | 答 |
|---|---|
| 教师教学的**直接依据** | **课程标准** |
| 教师教学的**主要依据** | **教科书（教材）** |
| 衡量各科教学质量的**重要标准** | 课程标准 |
| 课程计划的**具体化** | 课程标准 |
| 教材编写、教学、评估和考试命题的**依据**、国家管理评价课程的基础 | 课程标准 |
| 教材的**具体化** | 教科书 |

易混补充：**教材≠教科书**（教材含音像制品，范围更大）；**教材的主体＝教科书**，**教科书的主体＝课文**。

## 三、课程设计（开发）模式 vs 课程评价模式（两套，别混）

**设计/开发模式＝3 种**
| 模式 | 提出者 | 关键词 |
|---|---|---|
| 目标模式 | **泰勒** | 目标→内容→方法→评价（泰勒原理）；**最关键＝确定课程目标**；目标三来源＝学生、当代社会生活、学科专家建议 |
| 过程模式 | **斯腾豪斯** | 课程开发是**连续不断的研究过程**，边做边评边修正 |
| 实践模式 | **施瓦布** | 植根**实践情境**，靠**审议**解决具体问题，教师在编制中起主导 |

**评价模式＝5 种（人物一一对号）**
| 模式 | 提出者 | 抓手 |
|---|---|---|
| 目标评价 | **泰勒** | 看预设目标达成度 |
| 目的游离 | **斯克里文** | 评价脱离预设目标，看实际发生了什么 |
| CIPP | **斯塔弗尔比姆** | 背景-输入-过程-成果 |
| CSE | **斯太克** | 加州评价研究 |
| **差距模式** | **普罗佛斯** | 设计→装置→**过程**→结果→成本效益，第三阶段＝**过程评价** |

判据：**"怎么编课程"→设计模式；"怎么判课程好不好"→评价模式。** CIPP/CSE 出现在"设计模式"选项里是错的。

## 四、课程词源：提词 vs 写书（用户两连错）

| 人物 | 贡献 |
|---|---|
| 唐·孔颖达 | 我国**最早使用**"课程"一词（《诗经》注疏，此处比作"伟大的事业"） |
| 宋·朱熹 | 最早赋予**现代意义**（《朱子全书·论学》，功课及其进程） |
| **斯宾塞** | 西方**最早使用/作为专门术语**（《什么知识最有价值》，原意"跑道"） |
| **博比特** | 最早用于专门**领域**：1918《课程》＝**第一本课程理论专著**；提出**活动分析法**（为泰勒目标模式提供方法论依据） |
| 泰勒 | **现代课程理论之父＋课程评价之父**（没写"第一本"） |

判据：**问"最早出现课程一词/术语/《什么知识最有价值》"→斯宾塞；问"第一本专著/活动分析法"→博比特。**

## 五、课程类型六组（分类标准＋例子，用户点过"讲一下课程类型"）

| 分组 | 分类标准 | 内容 |
|---|---|---|
| 学科 vs 活动 | 课程内容的**固有属性**（教什么） | 学科＝知识中心（六艺七艺、四书五经），最古老最广泛；活动＝经验课程，**杜威**系统论证、**卢梭最早提出** |
| 分科 vs 综合 | 课程内容的**组织方式**（怎么教） | 分科≈学科；综合四形式见下 |
| 显性 vs 隐性 | **表现形式**（有无计划性） | 隐性四形式：观念性（校风学风/教师理念）、物质性（建筑环境/伟人画像）、制度性（校规班规/班级管理方式）、心理性（师生关系、心态与行为方式） |
| 必修 vs 选修 | 设置要求/学习要求/选课自主性 | **等价不等量**，无主次 |
| 国家/地方/校本 | 设计开发**管理主体** | **只看谁开发的**：某校开设（即使是当地民间音乐/太极拳）→**校本** |
| 基础/拓展/研究 | **课程任务（目标）** | 基础＝双基三基（必修）；拓展＝特殊能力；研究＝探究态度与能力（重过程） |

**综合课程四形式（由低到高，口诀「关心荣誉」）**
| 形式 | 特征 | 例 |
|---|---|---|
| 相关（最低） | 保留原学科独立性，A与B | 物理与化学、政治与历史 |
| 融合 | 有内在联系的学科**合成新学科** | 动/植/微/生理/解剖/遗传→**生物学** |
| 广域 | 合并**相邻学科**（并列） | 地理＋历史→**社会研究**；物化生→综合自然科学 |
| 核心（最高，＝问题课程） | **以问题为核心** | 环境污染、贫富差距、战争 |

判据：见"问题/环保/贫困/战争"→**核心**；"合并相邻学科"→**广域**；"合成一门新学科"→**融合**。

## 六、课程其他常考对照

- **古德莱德五层次**：理想（专家·"应该"）→正式（**教育行政部门**实际开设，含课程计划/教材）→领悟（教师领会）→**运作（教师课堂实际实施）**→经验（学生实际得到）
- **课程内容组织三原则（泰勒）**：**连续性＝同一要素反复出现；顺序性＝由浅入深；整合性＝横向联系（知识+能力、学科+生活）**。"发展性/持续性/适切性"都不是这三条。
- **课程资源开发利用四原则**：共享性、经济性、时效性、**因地制宜**（"互补性"是造词）。
- **课程实施/编制/计划**：题干是**动词串**（分析·选择·设计·实验·评价的整个过程）→**课程编制**；"把新的课程计划付诸实践"→**课程实施**；**课程计划**是名词（对学校全部教育教学工作的整体规划）。
- **隐性课程判据**：写在课程表/教学计划里的＝显性；氛围、奖赏（小红花/奖状）、师生关系、校风＝隐性。
- **校本课程开发主体＝教师**（不是专家/家长/社区）。

## 七、第四章教师章的已核实"无"与"有"（防题库补充版污染）

- 教师职业地位＝**四地位（政治/经济/法律/专业）**，**没有"职业声望"**（题库异版）。经济地位＝最直观/吸引人才的关键；政治＝前提；专业＝内在标准/指示器。
- 教师职业角色＝**六角色【传言教授家事】**：传道者/研究者/设计者组织者管理者/授业解惑者/**家长代理人（父母，也可称朋友）**/示范者，**没有"心灵培育者"**。
- "现代教师职业五特点（价值性/伦理性/教育性/复杂性/创造性）"＝**题库补充版本**，背诵稿与讲稿均无，不作考点。
- 教师劳动价值（社会价值＋个人价值统一；"得天下英才而教育之"＝个人价值）＝**背诵稿考点10 三级考点，网课039讲53:11讲过**——属有效考点，别当超纲弃用。

## 八、教师专业发展阶段（叶澜五阶段）抓手表

**顺序铁律：非关注 → 虚拟关注 → 生存关注 → 任务关注 → 自我更新关注**（不能颠倒）。

| 阶段 | 身份/时限 | 抓手 |
|---|---|---|
| 非关注 | 正式教师教育之前 | 还没想当老师，一般不考 |
| 虚拟关注 | **师范学习阶段（含实习期）** | 上四年师范、教育实习；**实习期别选生存关注** |
| 生存关注 | 刚入职新老师 | 我能不能留下来：学生喜不喜欢我、领导怎么看我；**强烈的自我专业发展忧患意识** |
| 任务关注 | 有稳定编制 | **盯教学本身**：学生成绩、怎么备课；"由我能行吗→我怎样才能行" |
| 自我更新关注 | 成熟教师 | **反思/自我规划/终身学习 ＋ 关注学生整体发展（个别差异、全面发展）** |

**最容易倒的一对（任务关注 vs 自我更新关注）**：题干只要落到"**哪种方式孩子/学生更容易接受、更适合学生**"→**自我更新关注**；只谈备课、分数、"我怎样才能行"→**任务关注**。别一看到"备课/教学"就归任务关注。

## 九、形式教育论 vs 实质教育论（第六章第二节·教学过程，背诵稿简答第5题）

| 阵营 | 主张 | 人物【口诀】 | 学科 | 心理学基础 |
|---|---|---|---|---|
| **形式教育论** | **重智轻知**（只练心智官能，知识无关紧要） | **洛克＋裴斯泰洛齐**【**两洛搞形式**】 | 希腊文、拉丁文、数学、逻辑、古典人文 | **官能心理学**（智力可自动迁移） |
| **实质教育论** | **重知轻智**（教有用的知识，智力增不增长不重要） | **赫尔巴特＋斯宾塞**【**巴斯看实质**】 | 物理、化学、生物、地理、法律等实用学科 | **联想主义心理学** |

**判别轴一句话：练脑子还是装知识。** 反向题陷阱：问"属于形式教育论的是"，选项里塞实质教育招牌句"传授对生活有用的知识"。

## 十A、课程管理（第五章第三节）：三时间点＋三级职责＋资源两分类

**三级＝国家、地方、学校；原因＝管理过于集中；优点＝增强适应性（固定词）。**

| 时间 | 文件 | 说法 |
|---|---|---|
| **1985** | 《中共中央关于教育体制改革的决定》 | 只"**提出**"地方负责、分级管理（问"最早提出"选它） |
| 1999 | 《关于深化教育改革全面推进素质教育的决定》 | **过渡** |
| **2001** | 《基础教育课程改革纲要（试行）》 | **明文规定三级课程管理**（问"明确规定/确立"选它） |

**三级职责分工**：国家＝总体规划、制定政策；**地方＝实施计划＋开发地方课程**；学校＝实施方案＋评价。

**课程资源按功能特点（易错）**：**素材性＝直接作用于课程、能"学进去"的知识技能经验**；**条件性＝间接制约的条件**（人力物力财力、电脑网络桌椅台灯）。口诀「素材进去、条件帮忙」。四分类全记：空间（校内/校外）、功能（素材/条件）、存在方式（显性/隐性，**网络属显性**）、性质（自然/社会）。

**国家/地方/校本判据补充**：依据**当地**政治经济文化民族需要开发＝**地方课程**；某校/某老师基于本地资源开发＝**校本课程**（"古镇研学""民族体育游戏"都算校本）。

## 十B、师生关系补丁（第四章第三节）

- 师生关系的**内容**＝社会道德上互相促进、人格上平等、教学上授受关系；**"主动与被动的关系"不属于**（反向题首选答案）。
- 师生关系**类型**抓手："表扬可能宠坏儿童，所以很少给予表扬"→**专制型**；"师生如父子"→**有关爱但没有偏爱**。
- 马太效应→**公平对待学生**。
- 综合素质评价原则：任何一种评价方法都不能全面反映学生发展状态→**多样性原则**。

## 十、能力素养四条与串选陷阱

【口诀 **自我组织语言**】＝**自我调控和自我反思能力**（与教育机智相关）／**组织教育和教学的能力**／**组织管理能力**／**语言表达能力**。
- "茶壶煮饺子——有货倒不出"→缺**能力素养**（不是知识素养）。
- 心理相容性措施（师生关系）反选词："指挥学生、发挥权力性影响"＝**错**项。
