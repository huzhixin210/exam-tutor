## 出题必做校验（题库质量纪律）

**题库解析与背诵稿冲突时，一律以背诵稿为准；冲突题弃用并登记 `做题系统/题库/6600题库_质量清单.md`。**

- 出题前校验：题干/答案/解析涉及的知识点，至少对一处关键表述核背诵稿原文（grep 关键词即可）。
- 已知坑例①：664t1dd021 把"职业声望"当成教师社会地位综合体现——山香体系只有**四地位（政治/经济/法律/专业）**，属异版超纲。
- 已知坑例②：ch4-01-076 把"学生心灵的培育者"算进教师职业角色——山香六角色口诀**「传言教授家事」**（传道者/研究者/设计者组织者管理者/授业解惑者/**家长代理人（父母，也可称朋友）**/示范者），无"心灵培育者"（讲稿里只是解释角色多样化的口语举例）。
- **答案反直觉时先读解析再判异版，别急着弃用**：题库答案与直觉相反（例："用木条和绳线做一个正方体模型"答"表现性目标"而非"行为性目标"），先看该题 analysis 是否给出**例证映射**，再拿那个例证去 grep 背诵稿——背诵稿原文写着艾斯纳表现性目标第④例证"通过使用铁丝与木头发展三维形式"，判定题库正确、且背诵稿自己标了"最易错"，这道题反而是最好的钉子题。只有解析也解释不通、背诵稿又查无原文时，才走弃用流程。
- 已知坑例③："价值性/伦理性/教育性"式的**现代教师职业五特点**——背诵稿与讲稿 grep 均 0 次，属题库补充版本。**词表型考点（五特点/六原则/四作用）最易被补充版污染**：凡题干以"××的特点有/包括"列出的并列词表，先 grep 背诵稿确认这张表存在，再决定用不用。
- **口诀纪律**：批改/讲解引用的口诀必须**照抄背诵稿原文口诀**，禁止临场自编（反面例：把六角色自编成"传授示管研心"，把不存在的"心"写进清单）。背诵稿没写的口诀先查网课讲稿，两边都没有就不给口诀。
- **学科易混对速查** → `references/学科易混对.md`：课程流派阵营图（同阵营不对立）、永恒主义 vs 要素主义、课程文本三层次与「直接依据＝课标 / 主要依据＝教科书」、设计三模式 vs 评价五模式、课程词源（提词→斯宾塞 / 写书→博比特）、课程类型六组与综合课程四形式、第四章教师章已核实的「有/无」（无职业声望、无心灵培育者）。**出这些考点的题之前先扫一眼对应条目**——这些正是用户反复倒的钉子，批改时的抓手直接照它写；新增已验证的易混对往这个文件里追加，不要另建文件。

- 处理流程：①背诵稿 grep 确认 → ②网课讲稿 grep 二次确认 → ③两处均无**先分性质**：与背诵稿/讲稿**冲突**（同一考点两套说法）＝异版题 → ④弃用该题、撤回错误扣分、错题本记"已作废"、质量清单登记、告知用户；若是背诵稿**根本没收录**的独立真考点（解析严密、有代表人物与镜像辨析，如「形式教育论 vs 实质教育论」）→ **保留出题、不弃用、不自编口诀**，讲解抓手直接改写题库 analysis 的对号句，错题条目注明「背诵稿暂无此考点，解析为准」，登记为背诵稿待补缺口。误把"缺失"当"冲突"会删掉整类真考点。
- **镜像辨析型考点的标准讲法**（形式/实质教育这类成对理论）：一句话给判别轴（"练脑子还是装知识"）＋每个阵营四个字对号（"形式练官能=重能力／实质给知识=重知识"）＋代表人物（实质＝斯宾塞·赫尔巴特）＋**点名反向题陷阱**（问"属于形式教育论的是"，选项里塞实质教育招牌句"传授对生活有用的知识"）。
- **分支：课本没有 ≠ 超纲**。山香有大量知识点是**老师课件补充、课本小字未收**的（如"教师劳动的价值"＝背诵稿考点10三级考点，网课039讲53:11老师原话讲过）——用户说"课本上好像没有"时，必须补一步**网课完整讲稿 grep 关键词+时间戳**：讲稿命中→判定有效，告知用户「老师讲过、课本可能漏收，建议对照背诵稿补上」，**不弃用**；只有背诵稿与讲稿都查无才算超纲。误判超纲会把真考点从复习池里删掉。
