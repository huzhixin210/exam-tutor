# 背诵机制与测验日历（2026-10-26 建，用户确认）

## 用户节奏（硬约束）
- **每天上午先背诵，下午做题**；考前一周背诵优于刷题。
- **背诵容易枯燥**：每天精背 **≤6 个考点**，宁可少而过手，不要多而划水；每考点配 1 个自检问题（能用自己的话说出即过），不搞全文默写；配口诀+趣味小任务（编段子/配例子）。
- 背不动标 △，第二天计划自动回炉。

## 文件约定（桌面/教编备考/）
- `思维导图/第X章.md`：每章一文件，每节列【考点N＋名称＋★级＋题型提示】，每章末尾附「本章错题钉子」（从错题本【考点标记】自动提取）。总目录 `00_总目录.md`。背诵先过框架再翻背诵稿。
- `背诵计划_YYYY-MM-DD起.md`：滚动 5 天计划，结构＝框架背 → 精背≤6考点（带口诀）→ 自检3问 → 趣味小任务。
- 生成逻辑：背诵稿 `### 考点N 名字 ★★ 二级考点（提示）` 正则提取即可，勿手工抄。

## 间隔重复落地
- 首背考点在第 2/4/7 天由做题批次换壳重考（不在背诵里复读）。
- 掌握度<60 的考点优先进背诵池；错题本【考点标记】行＝背诵重点清单。

## 测验日历（cron）
- **周测**：每周六 20:00，10 题（主教材×4＋补充×6）＝本周章节＋欠账＋滚动旧章（定时任务配置见 docs/接入AI.md）。
- **月考**：每月最后一个周六 20:00，20 题（主教材×8＋补充×12）＋月度成绩单。
- 定时任务的 prompt 里要写明：读 AGENTS.md → 按 SKILL.md 出题 → 结果推给用户。

## 开卷陷阱（重要）
用户有时结合课本答题（如 2026-10-26 第四章整章），成绩虚高不作掌握度依据：此类批次须在批改时标注，并**下一批闭卷换壳重验**同一考点（验出真钉子：开卷对的劳动特点闭卷又错）。

## 高频失分模式（2026-10 累计统计，出题与讲解优先覆盖）
1. **清单混入**：看着像对的新增词（独特性混入独立意义、社会形象混入职业形象、信念混入教育学价值、朋友关系混入师生关系类型、反思混入苏格拉底、任务混入学制要素）
2. **边界串位**：夸分赫立、昆体良(萌芽)vs夸美纽斯(正主)、复杂性(事情多)vs创造性(方法活)、实验=定量vs文化=理解解释
3. **清单漏选**：18 次，多为「最后一个没念到」（D位→C位），对策＝交卷前逐字过清单
4. **配对串位**：自然教育=卢梭、教育心理学化=裴斯泰洛齐、四步法=赫尔巴特
