# 题库同步（自己的服务器 = 题库真源）

场景：题库在自己服务器上，自己的 Hermes 更新后推上去，朋友的 Hermes 直接拉。
不用网盘、不用 scp、不用改仓库。

设计只有两条原则：
1. **只传原始题库**（`第一章.json`、`6600_第一章.json` 这类纯题目文件）。
   `已做.json`（刷题记录）、`弃用.json`（个人作废名单）、`进度/掌握度` **一律不上传** ——
   每个人的进度是自己的，混在一起会导致"跳过别人做过的题"。
2. **单向传输**。
服务器是题库唯一真源，本地是镜像 —— 谁都不会覆盖谁的编辑，不会出现冲突文件。

## 一、服务器一次性安装（5 分钟）

在服务器上（腾讯云网页终端也行）：

```bash
curl -fsSLO https://raw.githubusercontent.com/huzhixin210/exam-tutor/main/deploy/install_server.sh
sudo bash install_server.sh
```

脚本会：建 `/srv/exam-bank/data`、生成令牌、装成 systemd 服务 `exam-bank`、开机自启，
最后打印**地址**和**令牌**（只打印这一次，也存于 `/srv/exam-bank/token.txt`）。

⚠ 还得在云厂商控制台的安全组里放行该端口（默认 9120/TCP），否则外网连不上。

自检：`curl -s http://<你的IP>:9120/healthz` → `{"ok": true}`

## 二、发布题库（你自己，一次性 + 每次更新后）

本机：

```bash
python tools/publish_bank.py \
  --url http://<你的IP>:9120 \
  --token <令牌> \
  --dir "C:/Users/21056/Desktop/教编备考/做题系统/题库"
```

- 只上传 **sha256 变了**的文件，第二次跑全部 `skip`
- 最后上传 `manifest.json`，朋友的同步以它为准
- `--dry-run` 先看要传什么

建议存成环境变量，之后不用再打长命令：

```bash
export EXAM_BANK_URL=http://<你的IP>:9120
export EXAM_BANK_TOKEN=<令牌>
```

## 三、朋友的 Hermes 拉题库

```bash
python src/sync_bank.py --url http://<你的IP>:9120 --token <令牌> --root <他的 workspace>
```

或者直接让 AI 说一句「同步题库」，它调插件工具：

```
exam_bank_sync {"dry_run": true}    # 先看要下什么
exam_bank_sync {}                   # 真下
```

要预置地址（令牌仍走环境变量，不进配置文件）：

```bash
hermes config set plugins.entries.exam-tutor.settings.bank_url "http://<你的IP>:9120"
# 令牌写进 .env：EXAM_BANK_TOKEN=xxxx
```

定时同步（可选，`crontab -e`）：

```
0 6 * * * cd ~/exam-tutor && python src/sync_bank.py --url $EXAM_BANK_URL --token $EXAM_BANK_TOKEN >> ~/bank-sync.log 2>&1
```

## 四、安全性 / 版权

- **必须设令牌**：`install_server.sh` 生成 32 位随机串；没令牌一律 401（已实测）。
- 当前是 **HTTP**，题库内容明文过网。要继续收紧就上 nginx + 域名 + Let's Encrypt（或改用 SSH 隧道），
  别把带令牌的地址贴到公开群聊里。
- 题库是付费教辅内容，**只发给授权的人**，不要放进公开仓库、不要挂公开链接。
  仓库里 `workspace/` 与题库永远被 .gitignore 排除。
- 服务器端只接受 `.json`、拒绝路径穿越（`../`、子目录），单文件上限 64MB，写入是原子替换。

## 五、故障排查

| 现象 | 原因 | 处置 |
|---|---|---|
| 连接超时 | 安全组没放行端口 | 云控制台放行 9120/TCP |
| `HTTP 401` | 令牌不对/没带 | 对照 `/srv/exam-bank/token.txt` |
| `HTTP 404 manifest not published yet` | 还没发布过 | 先跑 `publish_bank.py` |
| `sha256 mismatch` | 传输被截断/代理改写 | 重跑一次；持续出现就查代理 |
| `systemctl status exam-bank` 起不来 | 端口占用或 python3 缺失 | `journalctl -u exam-bank -n 50` |
| 朋友那边题目数量不对 | 他本地有旧的、服务器没有的文件（不会被删） | 加 `--prune` 清掉本地多余文件 |
