# 设计说明

这套系统的每一条规则都来自"踩过的坑"，不是先设计后验证。下面说明为什么这么做。

## 1. 组卷为什么是 4:6

只用一本教材的题，会形成**单一来源偏差**：那本书没覆盖的考点永远考不到，覆盖了的反复考。
两本互补的题源（主教材 + 补充题库）按 4:6 混合，补充题库权重更高，因为它的题量更大、覆盖面更广，但主教材更贴合考纲。

实现见 `src/make_quiz.py`：`n3600 = round(n_new * 0.4)`，多选约 25%，同一考点最多 2 题，优先抽带 `tags` 的易错题（用日期做随机种子，保证当天结果可复现）。

## 2. 每批 9 新 + 1 复习

只做新题 → 会的一直会，不会的一直不会；只做错题 → 没有增量。
每批 10 题固定留 1 题给**衰减队列顶部**（保持率最低的考点），保证复习永久在线、不依赖人的自觉。

冲刺期批次节奏：每 5 批常规插 1 次专项 20 题（`--专项`），或触发式插队（红色考点 ≥4 个 / 同考点三连错 / 周测 <70%）。

## 3. 掌握度 = 会没会，保持率 R = 还记不记得

两个概念必须分开，否则复习计划会失真：

| 概念 | 含义 | 计算 | 怎么处理 |
|---|---|---|---|
| 掌握度 | 上次测出来的"会没会" | 答对 +10，答错 −15，下限 0 | <60 记为**未掌握**，要重学/重背 |
| 保持率 R | 现在还记得多少 | `R = 掌握度 × 0.5^(距上次复习天数 / 半衰期)` | 决定复习优先级 |

档位 0–6 对应半衰期 **1 / 3 / 7 / 14 / 30 / 60 / 120 天**。

### 升档为什么受"证据数"封顶

答对一次就升到高档位，会导致"刚学会的题 30 天不用管"——这是假的。
所以按累计跨日答对次数封顶：

| 累计跨日答对 | 最高档位 |
|---|---|
| 1 次 | 2（半衰期 7 天） |
| 2–3 次 | 3（14 天） |
| 4–5 次 | 4（30 天） |
| 6 次以上 | 6（120 天） |

答错或答「?」掉 2 档（惩罚重于奖励，因为遗忘的成本比复习高）。

### 状态分档

```
掌握度 < 60            → 未掌握（要重学，不是复习）
R / 掌握度 ≥ 0.90      → 稳固
0.75 – 0.90            → 松动
0.60 – 0.75            → 欠账
< 0.60                 → 红色（优先处理）
```

实现见 `src/decay.py`（纯函数、无副作用、27 个单测覆盖）。

## 4. 为什么错题必须换壳

原题重刷会记住"这道题选 B"，而不是考点。换问法、换选项、换情境，才能测出是否真的迁移了知识。

## 5. 六类失分模式

从几百道错题里归纳出的固定套路，每类配固定对策——比"下次注意"有用：

| 类型 | 表现 | 对策 |
|---|---|---|
| 人物/内容配对串位 | 张冠李戴，把 A 的观点记到 B 头上 | 人物—主张两列成对背，只背一对不做 |
| 分类标准混组 | 把"本质属性"当"社会属性" | 先问"按什么标准分"，再记条目 |
| "最早/第一"互换 | 《学记》与《大教学论》地位混 | 编年表：谁第一、谁第二，写死 |
| 名句出处归属 | 引文出处错配 | 名句单独成表，一旬一查 |
| 阵营词混入 | 内发论里混进外铄论人物 | 按阵营建卡片，不入阵营的一律存疑 |
| 清单漏选/混入 | 多选漏项（最常见） | 先默背口诀，再**数选项个数是否等于口诀字数** |

## 6. 为什么数据是纯文本

JSON + Markdown 的好处：可以 `git diff` 看进步轨迹、可以手工改、可以换任何 AI 接着用、不锁死在某个 App 里。
坏处是没有并发保护——所以规则里要求"同一时间只有一个会话在写"，写之前先读最新内容、编号取最大值 +1。
