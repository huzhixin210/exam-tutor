# 按节出题的映射表（题库/节关键词.json 底稿）

3600 题库没有节字段（id 里的 `ch6-01/ch6-02` 是"夯实基础练/能力提升练"，**不是节号**），6600 有 `topic`（专题N）。所以节范围靠两路：6600 用专题前缀，3600 用考点关键词。

## 怎么建一份新章映射
1. 列背诵稿拿节名：`背诵/第六章*_背诵稿.md` → 第一节…第七节，节名就是文件名里的那段。
2. `Counter(q['topic'])` 看 6600 有哪些专题，按背诵稿节名对齐（一节可能跨两个专题：原则+方法、组织形式+基本环节）。
3. 3600 侧列该节的考点名做关键词：取背诵稿里的考点标题原词，再加题库 kp 里的同义写法（OCR 常有"教学→敦学"，关键词挑不会被打错的词，如"中心工作"而不是"学校教育"）。
4. 跑一次 `--scope` 验证：候选数为 0 = 关键词全错；候选数远超该节题量 = 关键词太泛。（`--scope` 只用来验证映射，组卷仍由模型手挑，见 SKILL.md 出题流程）

## 坑
- 第六至九章的 3600 覆盖面比 6600 薄很多（第六章第一节 3600 只命中 4 道），此时 4:6 配比会让 6600 占绝对多数——**照实说明"该节 3600 题少，本批偏 6600"**，不要用别的节的 3600 去凑数。
- 关键词匹配用 kp 优先、题干兜底；题干含"教学任务"这类泛词会误收相邻节的题。
