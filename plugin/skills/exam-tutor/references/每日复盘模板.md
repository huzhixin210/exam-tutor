# 每日错题复盘 · 模板与生成算法

用途：每天 22:30（`python src/build_daily_review.py`）把当日新增错题变成第二天的背诵清单，并顺手归档当日做题会话。用户已确认下面这套格式，改动前先问。

## 一、成稿模板（逐字照抄结构）

```markdown
# 每日错题复盘 · <YYYY-MM-DD>

**今日错题 N 条（桌面 X 条＋企微 Y 条）→ M 个知识点**　|　每天 22:30 自动生成

> 用法：**📌 知识点 + 🧠 口诀 = 要背的**（念一遍→合上复述）；**✍️ 经验 = 做题方法**（扫一眼）；背不出的标 △。

> ✅ 今日做题会话已结束（HH:MM 归档，共 N 条错题）

---

## ① 30秒速览

| # | 知识点 | 今日错 |
|---|---|---|
| 1 | 考点8 教师劳动的特点（五组十个） | 2次 |

---

## ② 知识点清单（按章节）

### 第四章第一节

#### 考点8 教师劳动的特点（五组十个）（错96、103）　⚠️今日错2次

**📌 知识点：复杂性与创造性（一级）→ 连续性与广延性（二级）→ …（背诵稿▍骨架原文）**

**🧠 口诀：【全一样】＝教育目的的全面性、…（背诵稿▍口诀原文；无口诀则整行省略）**

**📌 要点：<抓手里的事实性列句，仅当背诵稿未匹配到骨架时补>**

- ✍️ 经验：只留做题方法（见X→选Y、数几个、对比判据），≤170字
- ✗ 今日错点：我答X　正确答案Y

---

## ③ 明日自测（合上文件答）

1. **考点8 教师劳动的特点** —— 📌知识点和🧠口诀能复述吗？

> 答不上来的，做题时说重考哪条，我出换壳题。
```

硬规则：
1. **作废题（标题含「作废」「补充版」）一条都不进文件**——不列、不提、不设「不必背」小节。
2. **知识点（📌）与做题经验（✍️）必须分离**：知识点＝要背的事实（定义/清单/口诀/年代/人物名言），经验＝做题方法。用户明确要求「知识点提出的然后加粗，好方便背诵」；把方法写进知识点或把清单写进经验都是返工。
3. **每条必须有 📌 知识点且加粗置顶**；知识点的来源优先级：背诵稿▍骨架原文 → 抓手里的事实性列句（如「七方法＝A、B、C…」）→ 都没有则手写补齐并核对背诵稿，**绝不编**。
4. 标题用**背诵稿的考点原名**（不是批改时自起的描述名）。
5. 同一考点当日错多次合并成一条，标「⚠️今日错N次」；30秒速览按错次降序，只放名字。
6. 章节顺序固定：第一章第一节 → … → 第五章第三节（order 字典排序；新增章时把该章各节追加进 order 字典，未列入的键归 99 排在最后）。**两个会话的条目混在同一章节下即可**，靠条目标题的时间戳与错题编号追溯来源，不单独分节。
7. **当日文件已存在＝追加合并**：保留已写知识点原文，新错题追加到对应章节，同考点又错则错题号追加进标题括号＋错次提高，速览/自测/头部计数重算；**不新建第二个文件、不覆盖丢旧内容**。
8. 当天没有新错题 → 只写「今日无新错题」，不硬凑；仍要写 `last_session_closed`。
9. 归档动作：`进度.json` 的 `last_session_closed` 写成 `<日期> <HH:MM>`，并在文件顶部插入「✅ 今日做题会话已结束」行。

## 二、生成算法（execute_code 内，无需人工读稿）

```python
import os, re, collections, glob, datetime
base = "<W>"
TODAY = datetime.datetime.now().strftime("%Y-%m-%d")   # 程序取日期，禁止手写

# 1) 背诵稿索引：章节前缀 → 文件（背诵稿会重命名，必须 glob 现查）
BK = {os.path.basename(p).replace("_背诵稿.md", ""): p for p in glob.glob(f"{base}/背诵/*_背诵稿.md")}

# 2) 定位考点块：按考点编号优先，名字关键词兜底
parts = re.split(r"(?=^#{3,4}\s*[一二三四五六七八九十]*、?\s*考点)", text, flags=re.M)
#   标题形如 "### 三、考点8 教师劳动的特点（五组十个） ★★★ …"
#   提取标题（去 ★ 后缀）、▍骨架段、▍口诀段：
#   r"▍骨架\s*\n+(.+?)(?=\n#|\Z)" / r"▍口诀\s*\n+(.+?)(?=\n#|\Z)"  flags=re.S
#   清洗：去 **、去尾部 "---"

# 3) 读错题本：re.split(r"(?=### 错题\d+（)") → 标题日期=今天才收
#    日期正则要兼容两种格式：old「（YYYY-MM-DD）」、new「（YYYY-MM-DD HH:MM）」
#    标题含「作废/补充版」直接 continue；抽【考点标记】章节·考点名、**我的答案**、**└解**

# 4) 抓手里拆两类：含 "＝≥"/包括/指的是 → 知识点要点；其余 → 经验
#    过滤批改时的口水句（"罚抄""这是你第N次""记牢这条"）

# 5) 按（章节, 背诵稿考点原名）合并 → nos 列表 → 排序（错次降序 → 章节序）
```

关键坑：
- 错题条目里的考点名是**批改时自起的描述名**（如「考点8 研究课题=创造性」），背诵稿原名是「考点8 教师劳动的特点（五组十个）」——**只能用「考点N」编号对齐**，靠名字匹配必然落空。
- 编号对不上（自起名无编号，如「教学相长三层」「在职进修三为主」）→ 名字关键词兜底；仍失败就**手写补一条 📌 知识点并核对背诵稿原文**（这类条目往往是清单式事实，直接写「A、B、C、D」），不要留空、不要编。
- 口诀段结尾常粘 `---` 分隔符，输出前 `re.sub(r"\s*-{2,}\s*$", "", s)`。
- 生成后 **自检「缺 📌 的条目」**：`re.split(r"(?=#### )", 全文)` 后挑出不含 📌 的块，逐条补齐再交付。
- 文件名必须等于当天真实日期（先 `date`）；写完 `read_file` 抽查文件头确认落盘。
