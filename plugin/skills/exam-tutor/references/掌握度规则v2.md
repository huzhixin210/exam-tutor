## 掌握度更新规则（v2 间隔验证模型，2026-10-24 起）
- **upd 的第一个动作永远是「打印目标章节现有全部键」**：每批都打印，不只新建键时才打印——其他会话可能刚在同一章写过，凭会话记忆里「这章是空的」就建新键，会造出与既有键并存的第二份数据（曾建出「考点_学校教育主导」与既有「考点6_学校教育」并存，事后要逐条合并回退）。看到语义相同的键就累加进旧键，不用新键。
- **任何「首答对=60、错=40、对+10/错-15」的算法都是旧版，已废止**：脚本里出现 60/40/±10/-15 就是走了旧记忆，立即改回 v2（首答对 45、同日再对 +3、跨日 +10、首次错 30）。**开批写 upd 前先把计分表原样粘成代码首行注释再对着写**：`首对45 / 同日再对+3(封顶50) / 跨日+10 / 跨三日+15 / 首错30 / 错-15 / 上限100`——跨会话最易漂回旧公式，凭记忆写分必错；交付前再看一眼打印出的转移序列（旧→新）是否符合这张表。哲学底线见 tutor-persona 技能：**答对≠掌握，跨天检索才算数**；同日连对只证明短期熟悉
- 每考点字段：掌握度/答题数/错题数/最近复习/跨日对次/next_review（upd 时缺字段就地补齐）
- 计分：**首次答对=45；同日再对+3（同日封顶50）；跨≥1整天答对+10；跨≥3天答对+15**；首次答错=30，之后错一律-15（下限0，上限100）。跨日判定＝今天与「最近复习」的日期差≥1天
- **封顶规则**：跨日对次=0 时上限84；跨日对次≥3 且最近一次跨日对距今≥7天，才可进入85+（已掌握档）
- 档位：<60欠账 / 60-69见过 / 70-84熟悉 / 85+已掌握
- 复习排期：答完按档位写 next_review——错题=次日；60-69=+2天；70-84=+4天；85+=+7/14/30递增（每次跨日答对成功才升一档间隔）；答错一律回退次日
- 更新方式：**必须用 Python json.load→改→json.dump**，不要用 write_file 覆盖（Hermes 防覆盖保护会拒绝未完整读过的文件）；错题本用 bash `>>` 追加
- **upd 的 right 参数逐题对照批改表写，写完核对打印输出**：批改表先定稿（每题 ✓/✗），更新代码按题号顺序逐行填 right，写完对照打印的转移序列（「考点X: 旧→新」）与批改表逐行核对——参数打错一次（False 误写 True）＝答错的题白加分、错题数不加，只能事后补丁（掌握度改回、错题数+1）；批量写入后花 5 秒对一遍打印输出是最便宜的校验
- **考点号跨节重复**（考点11 在第一节=原始社会教育、第二节=朱熹），upd 辅助函数不要硬编码章节——遍历"章节"字典按键名定位考点所在节，找不到时打印全部可用键再退出（一次 KeyError 会让整批写入回滚：json.dump 在末尾，前半段 upd 全部作废——修键后必须**从头重跑整批**，只补失败那条会丢前面的更新）
- **同日连批计分**：一天连刷多批时，同考点当日第二次起的「正确」按同日+3（封顶50），不是跨日+10——把每批的✓都按跨日对加分是掌握度虚高的主因，upd 前核对该考点「最近复习」是否已是今天
- **「封顶50」只管同日答对，不管答错**：同一考点同一天连考多题（如一个考点的 3 道换壳题写在同一批）时逐题按顺序结算——答对走 首对45/同日+3，答错仍照 -15，不会因为当天已加过 3 分就免扣；也别把 3 道题合并成「一题对一题错」来算，逐题累加答题数和错题数才和批改表对得上
- **开卷/翻书作答注记**：用户自述某批是「结合课本做的/开卷」→ 该批掌握度数值标注为高估（在进度.json当前阶段注明「开卷，参考性打折」），**不按虚高值安排复习跳过**；下一至两批对该章考点出闭卷换壳重验，以重验结果为准修正掌握度
- **批改多步脚本的写盘顺序＝掌握度→错题本→进度.json，每步落盘后崩溃都能断点恢复**：先 json.load 检查掌握度文件是否已含本批转移（或 grep 错题本尾部最新编号）确认写到哪一步，只补未写的部分；**禁止重跑已落盘的 upd**（叠加会使掌握度双倍变动）——execute_code 的内核变量跨调用保留，崩溃后可先打印内存里的 m 确认状态再决定。错题条目长文本别用 f-string 承载（花括号占位符手滑一个字母＝NameError 炸掉整段且一条都没写入），用普通字符串＋日期占位符 replace 更稳
- **章节归属以背诵稿文件名为准，不按视频讲次标题**：身心发展规律/动因四论/四要素属**第二章第二节**（网课033/034讲次标题写"第三章第一节"系课程编号错位，背诵稿文件头部有注明）；新建考点键前先确认所属背诵稿文件名，误建进错章节键需要在 掌握度.json移键＋改错题本标题＋改进度.json 三处返工；反之若掌握度.json已有**历史遗留键名**（键名与当前背诵稿文件名对不上，如旧名键实际承载新章节内容），沿用现有键放内容、不改名——改名会破坏其他并行会话的引用，只需在进度.json 里备注对应关系
- **键名整体漂移**：掌握度.json 可能被其他会话按背诵稿整体重排（章节键名增删「与」字、考点号全部重编号，如旧「考点13_三字经学记思孟」变新「考点10_大学与学记」）——upd 第一步先打印「章节」字典的键列表核对实际键名与考点名，不要按会话记忆里的旧名写入；**新建任何考点键之前必须先打印该章现有全部键**：同义不同名的键（如已有「考点6_学校教育」又要建「考点_学校教育主导」）同样禁止新建——按语义并入既有键累加（答题数/错题数相加，掌握度按±10/−15 重算），临时键用完立即 pop；只看到过某章为空就重建键是错的前提假设（其他会话可能刚写过），空判断要在同一次读取里现查；遇 KeyError **禁止直接新建**同名考点（会造出与新体系重复的第二份数据），先在该章现有键里按语义找对应条目再写；若已误建重复键，按语义合并进对应键后删除临时键（答题数/错题数累加；答错或「?」类掌握度下调15×失分次数；答对类+10；最近复习取今天），合并完打印全章键列表确认无重复
- **归错考点会误伤掌握度**：同一道题可按语义归多个考点，选错键会让无辜考点分数暴跌（把"师生如父子/马太效应"归进"师生关系的作用"，连错两道直接把该考点打到 0）。归位前先读该题解析/背诵稿确认它考的是哪一条；发现归错立即**双向修正**——原键 +15 还原并错题数-1，正确键 -15 并错题数+1（两处都写 `最近复习`），并在批改消息里一句话说明改归到哪里，别默默改
