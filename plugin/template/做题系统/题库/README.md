# 题库目录

放你自己的题库 JSON，**不要提交到 git**（默认 `.gitignore` 已排除整个 `workspace/`）。

文件名规则（`make_quiz.py` 按名字找题）：

| 文件名 | 含义 | 每批占比 |
|---|---|---|
| `第一章.json` | 主教材题库（比例 40%） | 4 题/10 题 |
| `6600_第一章.json` | 补充题库（比例 60%） | 6 题/10 题 |

- `已做.json`：已出过的题 id（脚本自动维护，不要手改）
- `弃用.json`：作废题 id 数组（脚本自动跳过）
- 字段说明见 `docs/数据格式.md`

**章内没有题库文件时脚本会打印 `[缺题库]` 并退出。**
